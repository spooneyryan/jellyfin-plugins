Export and import

Jellyfin's own backups leave plugin data out. An export saves every user's saved queries with their owners' names, in one file (keep it safe: it holds private queries too); an import reads such a file back, here or on another server. Settings are in the file for reference and never imported.

Snapshots

The daily maintenance keeps copies of the saved queries (Daily snapshots to keep, above), and a copy is taken before every import, restore and other change of many queries at once. Restoring one makes the saved queries the snapshot's, after a copy of them as they are now. Check it first: the check changes nothing.
