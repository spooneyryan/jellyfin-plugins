Detached & ambiguous

A rating is detached when its item leaves the library, and goes back to it by itself when the item returns, or to the same title found elsewhere. When several copies match, the member already rated the copy, or another title (or the same file without its metadata) is at its place, it stays detached as ambiguous rather than guessed; below, Relink gives it to the copy you choose.

Web client problems reported by browsers

Parts of the web client User Ratings relies on that a browser couldn't find since the server started, so the User Ratings feature that uses them was off there. A Jellyfin update is the usual cause; a User Ratings update brings the fix.
